# WoW Smart Fishing

WoW Forever addon (Interface 16001). CurseForge project 1743389. Release: put a new `## vX.Y.Z` heading at the top of `CHANGELOG.md` and push it to main (the workflow tags the commit and runs BigWigsMods/packager), or push a `v*` tag. Only release when the user asks for it after testing in game.

## Rules

- Do not add `Co-Authored-By`, `Claude-Session` or any other AI signature lines to commit messages, PR descriptions or release notes.
- The CurseForge changelog comes from `CHANGELOG.md` (`manual-changelog` in `.pkgmeta`), not from commit messages.
- UI text: write Korean source strings as `L["..."]` (never at file load time; build strings inside functions so the language option applies). After adding or changing strings, add translations to `tools/translations.py` and run `python3 tools/gen_locales.py .` (it fails if a key is missing or format specifiers differ).
- Read game API values through `ns.Safe` / `ns.Str` / `ns.Num` (the Forever client can return secret values).
- `Data.lua` is generated by `tools/build_data.py` from the vmangos DB dump; do not edit it by hand. Keep `LICENSE.txt` (GPL-3.0) and `CREDITS.txt`.
- Before pushing: `python3 tools/test_sim.py .` (needs `pip install lupa luaparser`) must run without errors.
